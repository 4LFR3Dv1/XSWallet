XS WALLET

TL;DR Executivo • Plano de 11 Semanas • Janeiro 2026

1. Objetivo

Carteira desktop self-custody com atomic swaps entre BTC, Liquid e Lightning Network.

  • Princípios: Zero Trust + Crash Recovery
  • Diferencial: Sem servidor central de custódia, preimages criptografadas, MuSig2 key-path claims
  • Target: Usuários técnicos que querem controle total sobre seus fundos

2. Arquitetura

Camada Tecnologia Função
Frontend Electron + React UI desktop, IPC seguro
Core Go (xscore) Swap Engine, Vault, gRPC Server
RPCs Primários LND gRPC + elementsd JSON-RPC BTC/LN + Liquid
Provider Boltz API v2 (self-hosted) Atomic swaps, HTLCs
Storage SQLite WAL Crash-safe, preimages encrypted

3. Fases (11 Semanas)

Phase Semanas Entrega Principal
1. Core Fixes 1-2 Schema unificado, preimage encrypted, PIN lockout
2. Adapters + Watchers 3-4 LND/Liquid adapters, Node Manager mínimo
3. Swap Protocol 5-6 1 swap E2E com crash-recovery
4. Electron 7-8 IPC bridge, migração do frontend
5. Tx Management 9 RBF/CPFP bumper, fee estimation
6. Packaging 10 Installer assinado, E2E tests
Buffer 11 Hardening Week (10-15% contingência)

4. Riscos Principais

Risco Impacto Mitigação
MuSig2 complexo Alto Fallback script-path claim
Electron security Crítico Security Gate obrigatório antes Phase 4
Binary verification fail Crítico Fail-safe: não executa, UI erro acionável
