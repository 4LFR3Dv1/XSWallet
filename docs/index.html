Características Principais

Tecnologia de ponta para swaps atômicos com verdadeira auto-custódia

💼

Carteira HD

Compatível com BIP39/32/84/85. Derivação determinística com BIP85 para chaves de swap isoladas.

🔄

Atomic Swaps

Submarine, Reverse e Chain swaps via Boltz API v2 com verificação local de scripts HTLC.

🔐

Segurança Máxima

Argon2id + AES-256-GCM com rate limiting. Device secret opcional via OS keychain.

⚡

Taproot + MuSig2

Key-path eficiente com agregação MuSig2. Fallback script-path para máxima resiliência.

🖥️

Nodes Embarcados

bitcoind, elementsd e LND com download verificável (SHA256). Datadirs isolados por rede.

💾

SQLite + WAL

Banco embarcado com CAS otimista, event log completo e ledger de idempotência.
