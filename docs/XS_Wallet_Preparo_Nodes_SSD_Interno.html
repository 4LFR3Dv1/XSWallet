XS WALLET

Preparo de Nodes no SSD Interno

Mainnet Pruned + Integração com xscore/api-bridge/electron

Documento Guia de Preparo de Nodes (SSD Interno)
Versão 1.0.0
Projeto XS Wallet v0.2.x
Data 18 Fevereiro 2026
Escopo Bitcoin mainnet pruned local, sem Docker

1. Objetivo

Preparar um ambiente funcional para rodar o XS Wallet com validação local de consenso via bitcoind mainnet pruned no SSD interno, minimizando consumo de disco.

1.1 Checklist de Execução

  1. Criar estrutura base em ~/.xs-wallet (pastas nodes/* e config).
  2. Criar ~/.xs-wallet/config/bitcoin.conf com prune=20000, RPC local e credenciais.
  3. Subir bitcoind apontando para o conf e datadir locais.
  4. Criar XSWallet/core/config.local.mainnet.pruned.json com bitcoind.enabled=true.
  5. Rodar xscore na porta 9735.
  6. Rodar API Bridge com GRPC_HOST=127.0.0.1:9735.
  7. Rodar Electron via npm run electron:dev.
  8. Validar com getblockchaininfo, endpoint /ready e fluxo UI (wallet status, unlock, balances).
  9. Operação contínua: manter prune entre 12000-20000, sem txindex=1, com no mínimo 20 GB livres.

2. Estrutura de Pastas

mkdir -p ~/.xs-wallet
mkdir -p ~/.xs-wallet/nodes/bitcoin
mkdir -p ~/.xs-wallet/nodes/elements
mkdir -p ~/.xs-wallet/nodes/lnd
mkdir -p ~/.xs-wallet/config

3. Configurar Bitcoin Pruned

3.1 Arquivo de configuração

Criar: ~/.xs-wallet/config/bitcoin.conf

server=1
daemon=1
prune=20000
txindex=0
rpcbind=127.0.0.1
rpcallowip=127.0.0.1
rpcuser=xsrpc
rpcpassword=troque_essa_senha

3.2 Subir bitcoind

bitcoind \
  -conf=/Users/renan/.xs-wallet/config/bitcoin.conf \
  -datadir=/Users/renan/.xs-wallet/nodes/bitcoin
Nota: prune=20000 significa alvo de ~20 GB para blocos retidos.

4. Configurar xscore

4.1 Criar config local

Criar: XSWallet/core/config.local.mainnet.pruned.json

{
  "network": "mainnet",
  "data_dir": "/Users/renan/.xs-wallet",
  "db_path": "/Users/renan/.xs-wallet/xs-wallet.db",
  "bitcoind": {
    "enabled": true,
    "host": "127.0.0.1",
    "port": 8332,
    "user": "xsrpc",
    "password": "troque_essa_senha"
  },
  "elementsd": { "enabled": false },
  "lnd": { "enabled": false }
}

4.2 Rodar xscore

cd XSWallet/core
go run ./cmd/xscore --config ./config.local.mainnet.pruned.json --port=9735

5. Rodar Bridge e App

5.1 API Bridge

cd XSWallet/api-bridge
GRPC_HOST=127.0.0.1:9735 npm start

5.2 Electron

cd XSWallet
npm run electron:dev

6. Validação Rápida

  1. bitcoin-cli -datadir=/Users/renan/.xs-wallet/nodes/bitcoin getblockchaininfo
  2. curl http://127.0.0.1:3000/ready deve retornar status=ready
  3. Na UI: testar wallet status, unlock e balances

7. Operação com 100 GB

  • Manter prune entre 12000 e 20000.
  • Evitar habilitar txindex=1 em modo pruned.
  • Manter folga mínima de 20 GB no SSD.
Risco: se o SSD encher, o node pode degradar e corromper operação do wallet. Monitorar uso de disco regularmente é obrigatório.

8. Próximo Passo (Roadmap)

Após estabilizar Bitcoin pruned local, evoluir para F3/F6 do backlog: nodes.list/start/stop/restart completos no app e UI de Node Manager dedicada.
