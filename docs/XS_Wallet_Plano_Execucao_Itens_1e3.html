3. Backlog Executável

3.1 Item 1 - Refund Script-Path Completo

Fase A - Consolidar validação e artefatos

  • Manter validação de tx hex com witness/tapscript compatível com locked_intent.*.swapTree.refundLeaf.
  • Persistir artefatos em locked_intent.refund (estratégia, txid, raw hex, timestamp).
  • Negar broadcast quando validação falhar.

Fase B - Builder local da refund tx (BTC)

  • Construir tx de refund localmente para o caminho fallback (prioridade BTC) usando UTXO + refund leaf + control-block + destino canônico.
  • Assinar tapscript localmente e montar witness final sem depender de hex do provider como caminho principal.
  • Comparar/validar localmente o script path antes do BroadcastTx e manter provider hex apenas como fallback controlado.

Fase C - Integração e resilência

  • Teste de integração com restart entre fallback_script_ready e refunding.
  • Idempotência: reexecução não duplica broadcast nem quebra CAS/version.

3.2 Item 3 - Stream Nativo no Frontend

Fase A - Stream por swap

  • Endpoint nativo de stream para eventos de swap e consumo no hook de timeline.
  • Fallback automático para polling incremental quando stream cair.

Fase B - Stream global

  • Expor stream global (equivalente a WatchAllSwaps) para atualizar lista/histórico sem polling fixo.
  • Aplicar filtros de estado no cliente para reduzir ruído de UI.

Fase C - Hardening operacional

  • Backoff exponencial de reconexão, heartbeat e detecção de sessão expirada.
  • Métricas mínimas: eventos/s, reconnect count, lag de atualização.

4. Critérios de Aceite (Definition of Done)

  1. Refund de fallback executa com segurança (script-path validado) e artefatos persistidos no locked_intent.
  2. Watcher só faz broadcast quando a prova local de script-path é compatível com dados persistidos.
  3. Frontend recebe eventos em tempo real por stream nativo para tela de swap (sem depender apenas de polling).
  4. Queda de stream não quebra UX: fallback entra automático e reconecta.
  5. Testes de integração passam para fluxo terminal sem simulação (quando saldo/testnet disponíveis).
